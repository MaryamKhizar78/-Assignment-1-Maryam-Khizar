# Build a Task Tracker

## Project Goal
The goal of this project is to build a menu-based Python Task Tracker
that stores tasks in a JSON file and loads saved tasks when the program
runs again.

## Features
- Add tasks with a title.
- View all tasks with their status.
- Mark tasks as Done.
- Delete tasks.
- Save tasks in tasks.json using json.dump().
- Load saved tasks using json.load().
- Handle empty titles, invalid choices, invalid task numbers,
  and a missing JSON file.

## Requirements
- Python 3
- No additional libraries required.

## How to Run
1. Download mini_task_tracker.py.
2. Open a terminal in the project folder.
3. Run the command:

   python mini_task_tracker.py

## Project Files
- mini_task_tracker.py: Main Python program.
- tasks.json: Saved task data, created automatically.
- README.md: Project documentation.
